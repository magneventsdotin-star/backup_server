# Artist Data Directory

This directory contains all categorized, segmented, and individual category files for Magnivents artist registrations with location, pricing, and specialization metadata.

---

## 🔝 Data Sorting & Priority

All master files and individual category files are **pre-sorted with Location Priority**:
1. **Specific City & Metro Hubs at Top (Positions #1+)**: Artists with verified bases in *Ahmedabad, Bengaluru, Chennai, Dehradun, Delhi NCR, Goa, Haridwar, Hyderabad, Kerala/Kochi, Kolkata, Lucknow, Madhya Pradesh, Mizoram, Mumbai, Navi Mumbai, Pune, Punjab/Chandigarh, Rajasthan, Udaipur, Uttarakhand*.
2. **Pan India (Touring / Available Worldwide)**.
3. **Pan India (Available on Request)**.
